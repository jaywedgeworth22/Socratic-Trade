## Decisions & Trade-offs

- **No source changes.**  16.3.5 is a backport-only patch release.  Its contents
  (next/image disk-LRU 0-byte entry skip + empty-image reject, whole-app server NFTs under
  `output: 'standalone'` with an adapter, CSP nonce on loading/template script tags, `use cache`
  prerender signal retention) are all internal fixes.  There is no API, config, or codemod
  migration, so nothing in `src/**` or `app/**` needed to change.
- **`PLAN.md` intentionally not updated.**  The handoff protocol calls for `PLAN.md` to reflect
  scope/timeline/approach changes; a patch-level dependency bump changes none of those.
- **No codex-autofix round cap reached.**  Measured on 2026-09-21, at two points so the numbers
  stay unambiguous — `876f3f2c` (the round-3 tip, i.e. *before* the round-4 commit exists) and the
  round-4 tip:

  ```
  git log --oneline origin/main..HEAD | grep -F '[codex-autofix]'
  #   3 at 876f3f2c  ->  560388bf (round 1), c09ea27e (round 2), 876f3f2c (round 3)
  #   4 at the round-4 tip  (the three above + the round-4 commit)
  git log --format='%s' origin/main | grep -cF '[codex-autofix]'
  #   7 — unchanged by this PR: autofix commits that arrived via previously-merged main work
  git log --format='%s' | grep -cF '[codex-autofix]'
  #   10 at 876f3f2c  ->  11 at the round-4 tip  (the 7 above + this PR's autofix commits)
  ```

  The cap counts commits authored on the PR branch, so this is **round 4 of 10** — six rounds
  remain.  Only the PR-local number matters for the cap; the history figure is context, and its
  absolute value shifts by one for every further round on this branch.

  Quoting trap worth keeping: `--grep='[codex-autofix]'` — the form an earlier revision of this
  bullet used — is an *invalid* git regex and aborts with `fatal: command line,
  '[codex-autofix]': Invalid range end` (the bracket expression's `x-a` is read as a character
  range), so it cannot have produced the count that revision quoted.  Use `grep -F` on formatted
  subjects, or escape the brackets as `--grep='\[codex-autofix\]'`.
